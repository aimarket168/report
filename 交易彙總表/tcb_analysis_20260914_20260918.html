  • 淨值連續第二週落後大盤，而且落後的幅度沒有縮小。9/11 → 9/17 四個交易日，台灣基金淨值 -1.82%、台灣高科技 -2.00%；同一段時間加權指數 +0.22%、櫃買指數 +0.67%。逐日看：9/16 櫃買大漲 2.70%、兩檔淨值漲 2.18%、2.15% 跟得上；但 9/17 加權漲 0.96%、櫃買只跌 0.26%，兩檔淨值卻跌 0.68%、0.74%，落差最大。持股走勢和大盤明顯不同，這是上週已交辦、本週仍要投研說明的事。
  • 跌了才買，連續第三週成立。申購最多的 9/15（4,518 萬）與 9/14（3,408 萬）都是下跌日；申購最少的 9/17（2,051 萬）與 9/16（2,338 萬）都是上漲日。9/18 大漲 1.93% 當天，扣掉遠雄人壽 3,908 萬的保險帳戶配置，一般客戶申購 2,052 萬，仍是全週偏低的一天。
  • 漲了就賣，也是連續第三週。贖回最多的 9/16（2,618 萬）是本週唯一淨值大漲的一天（+2.18%、+2.15%），鉅亨投顧當天賣台灣基金 922 萬、台灣高科技 734 萬，是網路平台客戶的停利單。但本週賣的量比前兩週小很多——五天贖回合計只有 1.01 億——反彈日出場的人變少了。
  • 9/14、9/15 逢低進場的客戶目前還沒賺到錢。台灣高科技 9/14 淨值 63.18、9/15 61.83，到 9/17 是 62.69；台灣基金 9/14 76.70、9/15 75.15，9/17 是 76.27。9/18 加權指數再漲 1.93%，淨值要下週一才寄達，這一天很可能讓 9/15 進場的人回到成本以上，但 9/14 進場的還要看淨值能不能跟上大盤。
  • 匯率本週對海外型是順風。美元兌台幣從 9/11 的 31.639 走到 9/17 的 31.867、台幣貶了約 0.7%，海外型基金的台幣淨值因此多了一點；9/18 回到 31.781，吐回一部分。下週海外型淨值的匯率成分會比本週小。
