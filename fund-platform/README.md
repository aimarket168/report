# 基金平台經營績效

基富通證券與鉅亨證券投資顧問之 2014–2025 年個別財報營收、成本費用及稅後淨利成長分析。金額以新台幣百萬元顯示，原始數值與來源記錄保留於 snapshot JSON。

- 財報來源：公開資訊觀測站／公開資訊觀測站電子書。基富通代號 000025；鉅亨投顧代號 B00282。
- 基富通 2014 年尚未成立；2015 年為 12/15–12/31 設立初期，不能與全年直接比較。
- 基富通採收益合計、支出及費用合計；鉅亨採營業收入、營業成本加營業費用。差異於儀表板揭露。
- 2026/10 每股公允價值為使用者提供的時點估值，不能替代 1–10 月損益。尚未取得兩家公司同期間營收、成本及稅後淨利。
- 每筆年度數據附官方財報查詢網址及頁碼。
